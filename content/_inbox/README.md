# _inbox — content drop zone

Drop a folder here per new entry, e.g. `content/_inbox/<slug>/`, containing the
Instagram screenshots (caption/text) and the cover/hero image. Then ask Claude
Code to process it following `design_handoff_human_thread/CONTENT_WORKFLOW.md`.
Processed folders are emptied — images move to `/public`, text becomes an entry
in `content/articles/` or `content/posters/posters.json`.
